# `$` skill autocomplete for Pi

Autocomplete loaded Pi skills anywhere in a message, instead of only through `/` at the start.

## Install

```bash
pi install npm:@yassimba/pi-skill-autocomplete
```

Restart Pi, then type `$` anywhere in the editor. Continue typing to fuzzy-filter skills and press Enter or Tab to insert the selected `$skill-name` mention.

The extension only adds editor autocomplete. It does not alter skill loading or prompt submission.
