# HTML view

One focused file — a diagram, an infographic, or a short slide deck, whichever fits the point — for a UI, a layout, a state comparison, or a concept too dense for a chat fence.

- Match the product's colors, type, spacing, and components; use real labels and real data.
- Support desktop and mobile.
- Save as `show-me-{description}.html`, then open it for the user:

```
Bash(open path/to/show-me-{description}.html)
```
